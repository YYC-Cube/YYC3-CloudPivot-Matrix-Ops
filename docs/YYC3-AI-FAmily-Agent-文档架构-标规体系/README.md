## 四、目录不变量

1. 文件名统一为 `YYC3-AI-FAmily-Agent-{主题}-{子主题}.md`（ASCII 前缀 + 中文主题）
2. 全部文档使用《标头标尾》§三 的 Markdown 标头与 §五 的标尾
3. `file` 字段必须与磁盘文件名一致，`title` 必须与 H1 一致
4. 正文品牌统一写作 `YYC3`，路径与代码标识使用 ASCII `YYC3`
5. 日期基准：2026-11-08（批量规范化后同日对齐）
6. `tags` 必须为合法 YAML 序列，禁止 `[a],[b],[c]`
7. 每篇文档标尾必须包含 🌹 家族信物与版权行
