## 一、文档定位与适用范围

### 1.1 文档定位

本文档是 YYC3 AI Family 在**对话消息层**的设计宪法。它向下承接《沉浸交互-家人中心》的空间、身份与动效规范，横向复用《设计系统-完整方案》的令牌与组件规范，向上接受《五维驱动-闭环设计》的评估约束，确保「空间—身份—消息—状态—评估」五者同源。

```text

│                    对话层文档闭环关系                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │

│   1980 x 1020 画布 / 8 位家人 / 时钟环 / 头像与 Logo 编辑      │
│                          │                                  │

│   《交互气泡-设计文档》（本文）                               │
```

### 1.2 适用范围

| 场景 | 容器特征 | 采用形态 | 关键约束 |
| ---- | -------- | -------- | -------- |
| IDE 侧边栏 | 宽 420–520 px | 直铺式 | 信息密度最高，代码一等公民 |
| 独立 Agent 工作台 | 宽 640–800 px | 卡片式 | 身份可识别，内容可分区 |
| 沉浸式家人中心 | 1980 x 1020 px 全屏 | 轨道式群聊 | 无滚动条，中央时钟环，发言轮转 |
| 移动端 | 375–430 px | 紧凑卡片 / 底部抽屉 | 触控目标不小于 44 x 44 px |
| 管理后台 | 宽 1024 px 以上 | 卡片 + 表格 | 审计、权限、批量操作优先 |

### 1.3 设计原则

1. **工具优先**：不以社交聊天的圆角与尾巴削弱工具属性，先保证代码、表格、结构化内容的可读性。
2. **平等伙伴**：8 位 AI Family 成员头像同尺寸、光效同强度、动画同规格，仅以身份主色与功能符号区分。
3. **身份可识别**：任何一条消息都能在 0.5 秒内回答「谁在说、说什么角色、是否可信」。
4. **状态可感知**：发送、流式、中断、失败、同步、冲突六类状态均有明确的视觉与操作出口。
5. **编辑可同步**：头像与 Logo 的编辑结果，需在气泡、浮层、列表、通知中心同步生效。
6. **无障碍默认**：颜色不是唯一信息载体，动效尊重 Reduced Motion，键盘可完成主流程。

### 1.4 文档不变量

1. 每份文档均含标准 YAML 标头与 🌹 标尾。
2. 品牌统一写作 `YYC3`，路径与代码标识使用 ASCII `YYC3`。
3. `file` 与磁盘文件名一致，`title` 与 H1 一致。
4. 日期基准沿用目录基线 2026-11-08，本次修订日期为 2026-11-17。
5. 所有尺寸、色值、状态以本文令牌表为**单一事实源**，上游文档冲突时按第六章差异登记处理。

## 三、气泡形态选型原则

### 3.1 三类形态

| 样式类型 | 适用场景 | 核心特征 | 代表产品 |
| :--- | :--- | :--- | :--- |
| **直铺式（IDE 主场景）** | IDE 侧边栏对话、长代码输出、结构化方案、审计报告 | 无圆角气泡包裹，消息占满容器宽度，仅以背景深浅与左右缩进区分发送方，信息密度最高 | Cursor、GitHub Copilot Chat、GitLab Duo Chat |
| **卡片气泡式** | 独立 Agent 工作台、多轮复杂交互、多 Agent 家族对话 | 弱圆角矩形卡片，保留头像与角色标识，内容分区清晰，兼顾工具感与身份感知 | 豆包专业版、Claude 项目模式 |
| **微型气泡式** | 行内悬浮助手、错误提示、快捷问答 | 小尺寸圆角气泡，仅承载短文本或单段代码，随上下文就近展示 | VS Code 内联建议、IDEA 快速修复 |

> **IDE 场景结论**：侧边栏宽度固定在 420–520 px 时，优先直铺式，取消冗余圆角与尾巴，最大化代码与结构化内容空间；用户消息右对齐加主色填充，家人消息左对齐加中性底色。

### 3.2 选型决策规则

1. 容器宽度小于 560 px，且以代码或长文为主，选直铺式。
2. 容器宽度 560–900 px，且需要同时展示身份、工具、产物，选卡片式。
3. 容器为 1980 x 1020 全屏舞台，选轨道式群聊：中央时钟环承载身份，右侧或下方消息流承载内容。
4. 触发点位于代码行内、错误行或悬浮提示，选微型气泡，内容不超过 3 行。
5. 同一产品内允许形态并存，但**气泡结构、间距、图标、状态**必须全局统一。

### 3.3 三类消息对齐规则

| 消息来源 | 对齐 | 底色 | 强调方式 | 头像 |
| -------- | ---- | ---- | -------- | ---- |
| 用户 | 右 | 主色渐变 #3B82F6 → #2563EB | 白色正文，右下水滴圆角 | 24 px |
| AI 家人 | 左 | IDE #1E293B / 沉浸 rgba(10,10,10,0.80) | 左侧 4 px 身份主色竖条 | 24–32 px |
| 系统 | 居中 | 透明 | 弱化文字，前置状态图标 | 无 |

### 3.4 行业实践参照

| 来源 | 公开观察（截至 2026-11） | 可复用点 |
| ---- | ------------------------ | -------- |
| Cursor / Cline | 右侧垂直对话面板约 480 px，全宽直铺，代码块与编辑器主题联动 | 侧栏直铺 + 一键应用到文件 |
| GitLab Duo Chat | 左侧头像与名称，消息无气泡包裹，系统消息居中 | 用户、家人、系统三类消息严格分区 |
| VS Code Copilot Chat | 支持 @ 参与者与 / 斜杠命令，回复内嵌命令面板按钮 | 提及与命令的可视化渲染 |

### 3.5 多 Agent 家族落地原则

1. **统一底层组件**：结构、间距、图标栅格、代码块规范全局统一，保证跨家人体验一致。
2. **差异化品牌表达**：每位家人保留身份主色、角色图标与身份标签，形成稳定认知。
3. **职能强化**：安全类强化告警与审计样式，编程类强化代码与脑图能力，创意类强化多媒体内容渲染。
4. **主题默认**：深色为默认主题，同步适配浅色，对比度满足 WCAG 2.1 AA。

## 四、气泡结构与视觉规范

### 4.1 标准七层结构

单条家人消息从外到内遵循统一结构，保证多 Agent 场景一致：

1. **角色区**：头像或标识、成员名、身份标签（如「安全官」「编程助手」）。
2. **内容主体区**：文本、列表、代码块、表格、脑图、图表等富内容。
3. **语义高亮区**：告警、成功、警告等状态色标识块。
4. **元信息区**：生成时间、Token 消耗、模型版本、耗时。
5. **操作栏**：悬停显示，包含复制、重新生成、插入编辑器、收藏、反馈。
6. **引用区**：关联代码文件、文档片段、历史消息、社区来源。
7. **扩展区**：快捷按钮、后续建议、相关问题推荐。

### 4.2 视觉变体

| 变体 | 用途 | 边框 | 底色 | 典型场景 |
| ---- | ---- | ---- | ---- | -------- |
| filled 填充型 | 默认、用户消息、核心结论、高优告警 | 无 | 主色或身份色低透明度填充 | 结论、告警、确认 |
| outlined 线框型 | 引用内容、外部文档、第三方信息 | 1 px 中性或身份色 | 透明 | 引用卡、社区来源 |
| plain 极简型 | 系统提示、状态更新、思考折叠区 | 无 | 透明 | 正在思考、已同步 |

### 4.4 群聊与多 Agent 协作

沉浸式家人中心是多人聊天室，消息层需在「多声部」中维持单一焦点。

| 规则 | 说明 | 视觉表达 |
| ---- | ---- | -------- |
| 焦点发言制 | 同一时刻仅一位家人处于主发言态 | 头像霓虹环 + 外圈指示灯 100% 亮度 |
| 旁听降权 | 其余并行回复降权展示，不抢占主视线 | 透明度降低，保留可展开入口 |
| 连续消息合并 | 同一家人 60 秒内或不超过 3 条连续消息合并 | 合并为消息组，仅首条显示角色区 |
| 交接卡 | 一位家人将请求转交另一位家人 | 「我已将请求转交给…」卡片 + 交接箭头 |
| 提及 | 用户或家人以 @ 指定成员 | 身份色 chip，点击定位成员浮层 |
| 私聊 | 双击成员头像进入一对一 | 顶部标识「私聊 · 成员名」 |
| 广播 | 系统面向全体成员的通知 | 居中系统消息，无头像 |
| 打断 | 用户点击停止生成 | 消息尾部标记「已中断」，提供继续与重试 |

并行编排遵循《家人中心》的 IntentGateway 与 Meta-Oracle 机制：**路由由言启·千行负责，汇总与决策由元启·天枢负责**，消息层只呈现结果，不自行改变编排顺序。

### 4.5 消息状态机

| 状态 | 触发 | 视觉 | 可用操作 |
| ---- | ---- | ---- | -------- |

## 七、IDE 编程场景专属渲染

### 7.1 代码块

代码是编程对话的核心内容，按一等公民设计。

1. **容器**：独立深色容器，顶部固定语言标签栏，右上角常驻「复制」「插入到编辑器」「新建文件」。
2. **排版**：默认显示行号，等宽字体，行高 1.6，支持横向滚动；长代码默认折叠前 30 行，展开后支持锚点跳转。
3. **增量 diff**：修改类回复直接渲染对比视图，新增行绿色底、删除行红色删除线，替代纯文本描述。
4. **上下文关联**：代码块底部展示「引用自 #文件名」，点击跳转到 IDE 对应文件行号。
5. **安全**：代码块内的密钥、令牌、内网地址按第十三章规则脱敏展示。

### 7.2 思考过程

1. 默认折叠为「思考中」状态条，展开后按「需求理解 → 方案拆解 → 技术选型 → 代码生成 → 风险提示」分层。
2. 每步独立子区块，支持单独跳转、复制关键结论。
3. 灰色弱视觉权重，与最终输出形成明确层级差。
4. 用户可随时打断，打断后保留已完成步骤，标记「思考已中断」。

### 7.3 上下文引用

| 类型 | 样式 | 交互 |
| ---- | ---- | ---- |
| 行内引用 | #文件名:行号 | 悬停预览文件内容 |
| 块级引用 | 独立小型卡片 | 点击展开完整片段 |
| 选区引用 | #selection chip | 显示选区行数与语言 |
| 报错引用 | #error chip | 展开堆栈与修复建议 |
| 工作区引用 | @workspace chip | 展示检索范围与命中数 |

### 7.4 工具调用卡

1. 展示工具名、调用参数、返回状态、耗时。
2. 高风险工具（写入文件、执行命令、访问网络）需显示权限确认，未确认前不执行。
3. 输入输出默认折叠，敏感字段脱敏。
4. 失败时显示错误码、原因与重试入口。

### 7.5 产物面板

1. 支持 Preview / Code / Data 三页签。
2. 支持 Mermaid、React 组件、CSV、Markdown 预览。
3. 支持全屏切换与导出，导出动作记入审计日志。

## 十、沉浸式家人中心融合规范

### 10.1 画布与分区

画布 1980 x 1020 px，全屏无滚动条。舞台由三层构成：底层为背景与全息连接线，中层为 12 小时时钟环与 8 位家人，上层为消息面板、成员浮层与编辑器。

| ---- | ---- | ---- |
| 中央标识 | 120 x 120 px | YYC3 品牌标识，60 s 旋转，可点击进入 Logo 编辑器 |
| 时钟刻度 | 12 主刻度 + 60 次刻度 | 主刻度每 1 小时，次刻度每 15 分钟 |
| 成员座位 | 8 个，45° 等分 | 06:00 为 0°，顺时针排布 |

### 10.2 时钟环与消息流联动

1. 成员发言时，对应位置指示灯亮起，头像霓虹环增强，座位脉冲加快至 1 s。
2. 消息进入消息面板后，角色区头像与时钟环座位使用同一张头像资源。
3. 点击成员座位，浮层展开并过滤该成员消息；再次点击取消过滤。
4. 双击成员座位进入私聊，消息面板顶部显示「私聊 · 成员名」。
5. 长按成员座位显示快捷菜单：查看资料、发起私聊、编辑头像、静音。
6. 发言轮转顺序由元启·天枢编排，消息层只做指示，不改变顺序。

### 10.3 成员浮层与气泡

浮层内展示头像、昵称、在线状态、最后发言时间；浮层底部提供「查看对话」与「私聊」两个入口。浮层与气泡的角色区共享同一身份主色，避免同一成员出现两种强调色。

| -------- | ---- | ---- | ---- |
| 成员浮层 | 80 x 80 px | 圆形 | 身份主色 2 px + 霓虹外发光 |
| 消息角色区 | 32 x 32 px | 圆形 | 身份主色 1 px |
| 会话列表 | 24 x 24 px | 圆形 | 无 |
| 行内提及 | 16 x 16 px | 圆形 | 无 |

编辑入口：点击成员头像打开头像编辑器，支持 JPG / PNG / SVG / WEBP，单文件不超过 5 MB，提供圆形裁剪、缩放、旋转、赛博滤镜、实时预览与保存同步。点击中央标识打开 Logo 编辑器，支持单文件不超过 10 MB，提供尺寸、位置、旋转、发光强度、版本管理与默认恢复。

### 10.5 编辑结果的同步与反馈

1. 保存后上传云存储，生成带版本号的 URL，更新数据库并推送变更。
2. 同步范围：Web、iOS、Android、Windows、macOS、管理后台，以及家人中心、聊天界面、用户资料、通知中心。
3. 消息层需呈现同步状态：同步中显示进度，成功显示绿色提示，失败显示原因与重试，部分失败列出失败端，版本冲突提供选择。
4. 离线时进入本地队列，恢复网络后按版本号增量同步，旧缓存标记失效。
5. 头像或 Logo 更新后，历史消息中的头像同步刷新，不保留旧图，避免身份错乱。

### 10.6 消息范围

| 范围 | 入口 | 视觉 | 可见性 |
| ---- | ---- | ---- | ------ |
| 群聊 | 默认 | 正常气泡 + 成员身份 | 全体家人与用户 |
| 私聊 | 双击成员 | 顶部私聊标识 | 用户与该成员 |
| 广播 | 系统触发 | 居中系统消息 | 全体 |
| 通知 | 同步、告警、任务 | 右上角通知中心 | 按权限 |

移动端补充规则：

1. 触控目标不小于 44 x 44 px，操作栏常驻或长按呼出。

## 十二、无障碍与国际化

### 12.1 无障碍

1. 正文对比度不低于 4.5:1，大字与图形不低于 3:1，满足 WCAG 2.1 AA。
2. 所有交互元素具备可见焦点态，Tab / Shift+Tab 可遍历，Esc 关闭浮层。
3. 快捷键：Enter 发送，Shift+Enter 换行，↑ 编辑上一条，Cmd/Ctrl+K 打开命令面板。
4. 图标按钮提供 `aria-label`，流式消息使用 `aria-live="polite"`，避免打断读屏。
5. 动效遵循 Reduced Motion，关闭旋转、粒子与循环脉冲。
6. 状态同时使用颜色、形状与文字，不依赖单一色觉通道。

### 12.2 国际化

1. 默认 zh-CN，支持 en-US；文案外置，不写死在组件内。
2. 日期、时间、数字按 `Intl` 本地化，时钟环仍以本地时区显示。
3. 支持 RTL：左右对齐、图标方向、连接线方向整体镜像，代码块保持 LTR。
4. 中英文混排时，代码与英文术语使用等宽或半角，避免中文字体拉伸。

## 十三、安全、隐私与审计

### 13.1 内容分级与脱敏

| 等级 | 示例 | 展示策略 |
| ---- | ---- | -------- |
| public | 公开文档、通用代码 | 正常展示 |
| internal | 内部路径、项目名 | 正常展示，复制时提示范围 |
| sensitive | 手机号、邮箱、密钥、内网地址 | 自动掩码，点击需二次确认 |

### 13.2 风险提示

1. 高危操作使用红色横幅，要求明确确认，必要时二次验证。
2. 外部引用内容标记「外部来源，未经验证」，防止提示词注入。
3. 工具调用展示权限范围，越权请求直接拒绝并记录。
4. 涉及删除、覆盖、发布的操作，提供影响范围与回滚说明。

### 13.3 审计与留存

1. 记录消息 ID、成员、时间、动作、结果、客户端与版本。
2. 审计日志只追加不修改，保留周期按项目合规要求执行。
3. 头像与 Logo 的编辑、同步、回滚均记入审计。
4. 导出、分享、插入编辑器等外发动作单独记录。

## 十四、性能与工程实现

### 14.1 性能目标

沿用《五维驱动-闭环设计》与《五维五高-五标五化》的指标口径：首字节小于 100 ms，完整响应小于 2 s，P99 小于 500 ms。气泡层补充以下目标：

| 指标 | 目标 | 手段 |
| ---- | ---- | ---- |
| 首 Token 呈现 | 小于 300 ms | 流式渲染、增量 Markdown |
| 长列表 | 500 条以上不卡顿 | 虚拟滚动、分页加载 |
| 动画帧率 | 60 fps | transform / opacity 动画，避免布局抖动 |
| 代码高亮 | 按需加载 | 语言包懒加载，超长代码折叠 |
| 图片与头像 | 懒加载 + 缓存 | CDN、版本化 URL、占位骨架 |
| 内存 | 会话切换不累积 | 离屏消息释放、缓存上限 |

### 14.2 组件结构

```text
Chat/
├── MessageList          # 虚拟滚动、分组、锚点
├── MessageItem          # 气泡容器、状态机
│   ├── RoleHeader       # 头像、成员名、身份标签
│   ├── ContentRenderer  # 文本、列表、表格、富内容
│   ├── CodeBlock        # 语言栏、行号、复制、插入
│   ├── DiffView         # 增删对比
│   ├── ThinkingPanel    # 折叠、分步
│   ├── CitationChip     # 文件、选区、报错
│   ├── ToolCallCard     # 参数、权限、结果
│   └── MessageActions   # 操作栏
├── ArtifactPanel        # Preview / Code / Data
├── Composer             # 输入、附件、@、快捷命令
└── SyncStatus           # 同步中、成功、失败、冲突
```

### 14.3 令牌落地

1. 使用 CSS 变量承载第五章令牌，Tailwind 与 shadcn/ui 只引用变量，不写死色值。
2. 深色与浅色通过 `data-theme` 切换，组件不感知具体色值。
3. 身份主色通过 `--agent-color` 注入，8 位成员共用同一套组件。
4. Figma 组件与代码组件一一对应，变体命名保持一致。

| 无障碍 | axe | 对比度、标签、焦点 |
