## 三、一致性对齐要点（本台帐裁定的口径）

1. **功能进度唯一视图** = 落档 36（七分类矩阵）；本台帐只管「文档资产状态」
2. **API/数据/部署/运维四权威** = 落档 18 / 19 / 34 / 26——01~15 目录中与之冲突的早期稿件一律以落档为准（不回写，标注于本表）
3. **IDE 相关旧文档**（12-用户指南、modules/dev 内）：功能已拆除（落档 36 §二⑥），相关描述段落属历史事实，P7 清理批统一加「已拆除」标注或归档
4. **docs:check 门禁范围**（0307 日志体系）不变；本台帐不纳入自动校验（人工维护，重大目录变更时更新）

## 四、维护规则

- 新增/迁移/归档目录 → 本台帐表同步更新一行（分类+说明）
- 每批次落档时若涉及 docs 结构变化 → 台帐随批更新并登记注册表
- 归档区只进不出（16-/归档-\*）；命名带日期批次
