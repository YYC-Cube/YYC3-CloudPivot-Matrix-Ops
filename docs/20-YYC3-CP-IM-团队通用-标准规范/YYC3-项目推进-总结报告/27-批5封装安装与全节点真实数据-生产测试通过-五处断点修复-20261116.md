## 二、五处断点修复（生产测试真机暴露，`3f2ad3f`）

| # | 断点 | 根因 | 修复 |
| ---- | ---- | ---- | ---- |
| 1 | 打包 UI 白屏 | `build:pages`（`--base=/` Pages 专用）覆盖 dist 后直接 electron-builder → 包内 `/assets` 绝对路径 file:// 404 | electron 6 个 scripts 显式 `vite build --base=./`，与 Pages 链彻底隔离 |
| 2 | 打包版 WS 断开 | PROD CSP `connect-src` 仅 `wss:` 无 `ws:` → file:// 源连 ws://localhost 被拦（Web 版 http 源放行故仅桌面断开） | 精确白名单 `ws://localhost:* ws://127.0.0.1:*`（不放泛 `ws:`） |
| 3 | 令牌首次配置 | Electron file:// origin localStorage 独立于 Web 版，安装版需单独配置 | CDP 走正规 UI 路径注入（与 Web 版同一「设置→WebSocket→粘贴令牌」流程） |
| 4 | index.html 误删 | 部署收尾清理临时文件时 `rm -f index.html` 误伤项目根入口文件 | `git checkout` 恢复；教训沉淀：清理命令禁用无路径限定的 rm |
| 5 | x64 下载失败 | electron-builder 下载 x64 electron zip 网络不稳定（400/TLS） | arm64 优先交付（本机架构）；x64 重试策略登记批 6 |
