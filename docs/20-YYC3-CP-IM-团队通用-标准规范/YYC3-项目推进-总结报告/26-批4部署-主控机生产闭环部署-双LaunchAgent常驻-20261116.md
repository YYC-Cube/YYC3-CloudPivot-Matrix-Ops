## 三、运维手册（主控机）

```bash
# 服务管理
launchctl list | grep com.yyc3          # 状态
launchctl kickstart -k gui/$(id -u)/com.yyc3.agent        # 重启 agent
launchctl kickstart -k gui/$(id -u)/com.yyc3.ops-panel    # 重启面板
launchctl bootout gui/$(id -u)/com.yyc3.ops-panel         # 停止
# 探活
curl http://localhost:3113/healthz      # agent（clients=已连面板数）
curl -I http://localhost:3118/          # 面板
tail -f ~/Library/Logs/yyc3/agent.log   # agent 日志
# 令牌轮换（新节点/泄漏时）
rm ~/.yyc3-cloud-matrix/agent-token     # agent 重启自动生成新令牌
# → 面板「系统设置→WebSocket」重新粘贴新令牌 → 保存
```

**新节点接入**：节点机部署 agent（`pnpm agent:install`，plist 改节点路径）→ 主控机面板 `follow-up-manager` 添加节点 → 分发同一令牌文件。
