## 二、图二矛盾双根因（「测试通过」却显示「异常」）

| # | 根因 | 修复 |
| ---- | ---- | ---- |
| 1 | `handleTest` **无条件** `toast.success("连接测试通过")`——失败也弹通过；且 `testConnection` 无返回值，UI 无从判断 | `testConnection` 返回 `{ok, detail}`；设置页与只读诊断页的 toast 均据实（成功带详情、失败带原因） |
| 2 | smoke 冒烟用 `max_tokens: 1` → 上游返回 **空 content**（`finish_reason=length`）→ 统一层按「空内容」判失败 | 改 **32 tokens** + 截断容忍（`choices` 非空即判定连通，detail 注明「输出被截断，连通性正常」） |
