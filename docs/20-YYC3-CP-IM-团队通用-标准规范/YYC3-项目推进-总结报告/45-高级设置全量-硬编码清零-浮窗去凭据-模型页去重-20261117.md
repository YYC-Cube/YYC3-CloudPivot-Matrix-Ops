## 一、高级设置全量（图一对齐）

添加/编辑模型表单「高级设置」现含 **6 组**：

| 组 | 项 | 语义 |
| ---- | ---- | ---- |
| API 格式 | OpenAI 兼容 / Anthropic Messages | 决定请求端点与认证头（落档 44 分流） |
| 输入类型 | 文本（恒选·锁定）/ 图片 / 视频 / PDF | 能力声明 |
| 模型能力 | 结构化输出 / 原生联网搜索 / 对话中系统消息 | 能力声明 |
| 推理等级 | 动态增删（从低到高，如 low/high/max） | 聊天可选强度梯度，声明位 |
| 推理参数映射 | JSON 文本（textarea，原样存储） | 上游特定思考参数映射 |
| 上下文/输出 | 32/64/128/256K · 8/16/32/64K | `maxOutput` 驱动请求 `max_tokens` |

类型：`ConfiguredModel.{inputTypes, modelCapabilities, reasoningLevels, reasoningParamMapping}`（叠加落档 44 的 `apiFormat/capabilities/contextWindow/maxOutput`），`addModel(extras)` 全量透传，编辑回填。

## 二、硬编码系列清零（图二/三）

**清空**：`BUILTIN_PROVIDERS` 的 `models` 对所有内置服务商置空（yyc3/zhipu/deepseek/ollama）——模型名不再由代码预置。
**迁移剔除**：`HISTORIC_HARDCODED_SERIES` 在 `migrateProviders` 中从用户本地持久化的内置服务商里剔除历史系列名（否则旧值继续渲染 chips）。
**动态发现**：详情页新增「从上游拉取模型列表」→ `GET {root}/models`（复用 `resolveRequestRoot` 路由，自动走同源反代），成功后写入 `provider.models` 供 chip 快捷添加。
**实证**：预置旧数据 `models:["glm-4-flash","glm-5"]` → 页面 `+glm-4-flash`/`+glm-5` chips 均消失，显示「从上游拉取模型列表」+「尚无系列列表」提示。

## 三、浮窗取消 API 设置（图四）

- 移除「OpenAI API 认证」输入框与显示/隐藏切换
- 顶部改为只读提示：「模型与密钥由『系统设置 → 模型设置』统一管理 · 本页仅可选择模型、测试连接、查看诊断」
- 诊断/测试的 Key **唯一来源 = 所选模型自身 `apiKey`**；浮窗不再回写 `aiApiKey`（实证：无 API 输入、无「显示」按钮）

## 四、AI 智能-模型管理 重复性评估与处置

**评估**：该页与「系统管理-模型设置」的数据完全相同（同一 SSOT），原「服务商注册表」展开区几乎是设置页的镜像 → **确认重复**。
**处置（保留路由，转型为诊断台）**：
- 服务商注册表 → 精简为**只读紧凑 chips**（label + Key 状态 + 「管理 →」跳设置页）
- 新增 **「问题分析」面板**：汇总所有非 active 模型，按失败原因分类给修复指引（Key 失效 → 核对 Key；CORS/不可达 → 反代；格式/空内容 → API 格式与模型名；未测试 → 点测试）——这是设置页没有的独特价值
- 保留：Stats、Ollama 本地模型刷新、已配置模型只读列表（含测试）、导出
- 写操作全在设置页（落档 44 已移除全部写入口）

**最终页面职责矩阵**：

| 页面 | 定位 | 可做 | 不可做 |
| ---- | ---- | ---- | ---- |
| 系统管理-模型设置 | **唯一编辑面** | 增删改服务商/模型、Key、高级设置、测试、激活 | — |
| AI 智能-模型管理 | 只读诊断台 | 测试、问题分析、导出、Ollama 刷新 | 任何增删改/导入/预设 |
| AI Family-模型设置 | 只读绑定面 | 成员模型选择、测试、问题分析 | 任何模型定义编辑 |
| AI 浮窗-配置 | 只读选择面 | 选模型、温度参数、测试 | Key 输入、模型增删改 |

## 六、口径说明

- 推理等级/输入类型/模型能力为**声明位**：存储与展示，不改变协议请求（工具调用/视觉需上游支持与调用方实现）
- 推理参数映射原样存储；引擎暂不注入请求（避免对不支持的上游造成 400），后续按 provider 适配
- 「从上游拉取」对 Anthropic-only 端点可能无 `/models`，会给出 HTTP 状态提示，可改手输模型名
- Mimosa 提示 i18n enterApiKey×2 为 UI 文案，口径不变
