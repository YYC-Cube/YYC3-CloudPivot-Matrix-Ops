## 一、背景与目标

落档 50 交付性能监控页时，趋势区明确标注「待接入时序存储后提供（不伪造曲线）」。本轮以**两条真实存在的时序路径**补齐，不开任何伪造口子：

| 路径 | 来源 | 窗口 |
| ---- | ---- | ---- |
| 前端会话级采样 | node-slice 聚合态（agent WS + OpsPanel 探针汇聚） | 10s × 环形 60 点 ≈ 10 分钟，sessionStorage 会话持久 |
| 服务端留存时序 | OpsPanel `/api/history`（app.py:160，唯一服务端时序） | 服务端窗口原样透传，每节点显示最近 60 点 |

## 二、useNodeTimeSeries（会话级采样 Hook）

- **口径同源**：`samplePoint()` 与概览卡 `agg` 完全同源（CPU=node.gpu 真实 CPU 利用率、内存=node.mem、GPU=metrics.gpus 均值、温度=node.temp）——**卡片与曲线必须一致**
- **采样节奏**：10s（与 `useOpsPanelMetrics` 探针轮询同频）；挂载即取首点
- **诚实性**：无任何节点时不采样（不制造全 null 点污染窗口）；指标缺失记 `null`，图表断线呈现；**不插值、不补零、不伪造**
- **生命周期**：模块级单例 + 引用计数（首消费者挂载启动、最后一个卸载停止），组件重挂不重置序列；`useSyncExternalStore` 消费
- **持久化**：sessionStorage `yyc3-node-ts-v1`（刷新保留、新标签页独立、解析失败静默从空窗口开始）

## 三、聚合性能趋势卡（SVG 三线折线）

- 三线 = **CPU（#00ff88）/ 内存（#aa55ff）/ GPU（#00d4ff）**，0-100% 固定轴（温度为 °C 量纲不入百分比轴，保留在概览卡）
- 网格 0/25/50/75/100 + 时间轴刻度（首/三等分/末，HH:mm:ss）+ 线尾圆点 + 图例（色点/名称/最新值/点数与窗口说明）
- `null` 断线（诚实呈现无来源区间）；**首点前显示「采样中…」占位**，绝不画假曲线
- viewBox 800×240，色值与概览卡一一对应

## 四、探针可达性 · 延迟趋势卡（/api/history 实测）

- **数据**：`useOpsPanelHistory` 轮询 `/api/history`（10s，5s 超时），载荷 `{history: {nodeId: [{ts, reachable, probe_ms}]}}` 原样透传（字段与 app.py:160 实测一致，无扩展推断）
- **每节点行**：probe_ms 黄色迷你折线（自动量程）+ 最新耗时 + 窗口可达率 + 时间跨度；**不可达点红色刻度标记、不连线**
- **门控**：与 `useOpsPanelMetrics` 同规则（demoMode 关闭 / opsPanelEnabled / baseUrl SSOT）；拉取失败如实置 error 并保留上次成功载荷，空态不撒谎
- 实测：7 节点全渲染（yyc3-22/45/33/n1/n2/77/66），其中 yyc3-45/66 可达率 0% **如实呈现**
