## 一、窗口不可移动 — 根因与修复

**根因**：`titleBarStyle: hiddenInset` 移除了系统标题栏，拖拽区须由 web 内容以 `-webkit-app-region` 定义——应用从未定义 → 窗口不可移动。

**修复**（`20a9eac`）：

1. `src/styles/index.css` 全局规则：
   - `.yyc3-app-drag`（`-webkit-app-region: drag`）
   - 交互元素兜底 no-drag：`button / input / select / textarea / a / [role=button] / [role=menuitem] / [data-radix-popper-content-wrapper] / .yyc3-app-no-drag`
2. `TopBar` 根元素挂 `.yyc3-app-drag`——整条 48px 顶栏可拖动，交互元素保持可点击
3. Web 浏览器忽略 `-webkit-app-region`，不影响 Web/PWA

**验证（CDP 实测）**：TopBar `appRegion=drag`、内部按钮 `appRegion=no-drag`、页面完整渲染。

## 二、logo 配置 — 诊断结论与强化

**诊断**：素材链本身正确——`public/yyc3-icons/macOS/1024.png` 为正牌 YYC³ logo（青色云形，1024×1024 有效 PNG）→ 包内 `icon.icns`（808K, 1024 icns）已正确生成。用户看到默认图标的原因判定为 **Dock 图标缓存**（同 bundle id 重装不刷新图标缓存）。

**强化**（同 commit）：

1. `resources/icon.icns`（官方 logo 经 iconset + iconutil 生成，614KB）落位 **buildResources 默认路径**——electron-builder 图标解析最高优先，打包链不再依赖 `mac.icon` 相对路径回退
2. 安装后执行 `killall Dock` 刷新图标缓存
3. 包内 icns 复验有效

## 三、运维提示

```bash
# Dock 图标显示异常（重装同 bundle id 后）——缓存刷新
killall Dock

# 自定义图标替换流程：更新 public/yyc3-icons/macOS/1024.png
# → 重新生成 resources/icon.icns（iconset+iconutil）→ 重新打包 → killall Dock
```
