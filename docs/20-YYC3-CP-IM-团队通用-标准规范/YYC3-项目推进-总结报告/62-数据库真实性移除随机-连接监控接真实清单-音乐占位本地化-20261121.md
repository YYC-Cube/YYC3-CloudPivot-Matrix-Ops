## 一、数据库域：不再伪装成功

| 项 | 之前 | 现在 |
| ---- | ---- | ---- |
| 连接测试 | 3 步假动画 + `Math.random() > 0.2` 决定成功/失败 | 300ms 后如实置 `error`，提示「浏览器无法直连数据库，需服务端代理（当前未接）」 |
| SQL 快速测试 | `MOCK_SQL_RESULTS` 固定结果 + 随机耗时；INSERT/UPDATE 固定返回 `affected_rows=1` | 删除全部假结果；危险语句仍安全拦截；其余明示「SQL 执行未接后端，不返回模拟结果」 |
| 连接监控 | 读 `connectionManager`（从未被 `db-conn-slice` 填充），永远「连接不存在」 | 读 `db-conn-slice` 真实连接清单；选中后展示真实 host/port，并明示「健康检查未接后端」 |

> 说明：数据库三套 store 的**架构合并**仍未做（`/database` IndexedDB、`/db-connections` localStorage、监控内存态）；本批先消除假行为，合并留待后续。

## 二、音乐占位资源本地化

- `getPlaceholderCover(label, width, height)` 改为本地 SVG data URI（零网络请求），支持尺寸与文字。
- `MusicData.ts` 内头像 / 相册照片 / MV 缩略图 12 处硬编码 `via.placeholder.com` 全部替换为本地占位。
- `MusicSpacePage.tsx` 5 处 `onError` 回退同样改为本地占位。
- 结果：`via.placeholder.com` 引用 **0**。
