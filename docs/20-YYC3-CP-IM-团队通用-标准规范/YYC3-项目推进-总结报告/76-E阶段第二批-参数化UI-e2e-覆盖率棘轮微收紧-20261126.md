## 一、参数化 modal e2e（agent-linked 第 4 例，1.4s）

`qa2 部署模型（计划）`全流程自动化：卡片点击 → executeAction 分流到参数 modal（schema 来自 GET /actions 实时回读）→ 必填 MODEL/SERVED_NAME 填参 → 提交 → toast「执行成功 · plan-only」（plan 模式：无 CONFIRM → 脚本只输出部署计划，exit=0，**不动 DGX**）。

## 二、开发中实测三坑（均已修）

1. **agent 进程 stale**：publicAction 回传 args 的编辑落地后未重启 agent——GET /actions 返回 deploy `args: null` → modal 无字段。重启即恢复 7 键 schema。
2. **GET /actions 启发式缓存**：浏览器对同 URL GET 复用旧响应（旧 null-args body）——客户端加 `t=${Date.now()}` 防缓存。
3. **非必填留空不得过 pattern**：NODE_ALIAS 空串命中 400 `参数不合法`——双侧修正：**agent 端非必填空值跳过校验且不注入 env**（采用脚本默认）；**客户端仅提交非空参数**（空值不进 args）。

## 三、覆盖率棘轮微收紧

新增 e2e 不计入覆盖率；单测侧本批无新增——**棘轮 statements 54→54.5 微收紧**（实测 54.78 过线），验证 coverage 门禁 EXIT=0。lines/functions/branches 维持 55/56/42。
