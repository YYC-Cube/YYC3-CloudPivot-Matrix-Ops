## P1 真实化收尾（详细方案）

| 子项 | 动作 | 验证 |
| ---- | ---- | ---- |
| N1 | 删除 `modules/ai-family/components/AgentSkills.ts`（30 号审计实证零引用） | grep 零残留 + 三门禁 |
| N2-a | 删除 `src/app/stores/dashboard-stores.ts`（@deprecated，生产零引用，仅 global-data-interoperability.test.ts 引用 → 同步删除该 legacy 测试） | 三门禁 |
| N2-b | `yyc3-storage.ts` 移除 legacy createLocalStore 键注册（yyc3_nodes / yyc3_deployed_models 等 503-511 段） | tsc + grep |
| N2-c | 用户浏览器残留旧键（yyc3_deployed_models 等）无害化说明：键注销后无消费方；存量数据经「存储管理」页可查可清 | 文档登记 |
| N4 | `docs/API-DOCUMENTATION.md` 头部加 DEPRECATED 标注 → 指向落档 18 | 目视 |

**P1 退出标准**：三门禁全绿 + `grep AgentSkills/dm-1|DEFAULT_DEPLOYED_MODELS` src 零命中 + 提交。

## P2 supabase 解耦（详细方案）

三步走（消除 30 号审计 N3 矛盾：18 号「不得接线」vs App.tsx 实际接线）：

| 步 | 动作 | 涉改 |
| ---- | ---- | ---- |
| 1 | 新建 `src/app/lib/mock-auth.ts`：`ghostSignIn / isGhostMode / getLocalSession / signOutLocal`（自 supabaseClient 提取纯本地逻辑，语义不变） | 新文件 |
| 2 | 摘 import：App.tsx（getSession/signOut → getLocalSession/signOutLocal，兜底账号文案改中性）、db-queries.ts（删 `void supabase` 占位）、TopBar.tsx / IntegratedTerminal.tsx（isGhostMode 改 mock-auth）；TopBar.test.tsx mock 路径同步 | 4 文件 + 1 测试 |
| 3 | 删除 `supabaseClient.ts` / `supabaseClientReal.ts` / `supabaseClientReal.test.ts` | 3 文件 |

**P2 退出标准**：三门禁全绿 + 浏览器实证（GHOST 一键进入 → 登出 → 再进入，会话恢复正常）+ `grep supabaseClient src` 零生产引用 + 提交。

## P3 双端一致性验证（批6续收口）

最新 dist 已含 merge 修复（user 节点不被快照清除且状态由探针驱动）+ ssot v3 迁移。Web(3118) 与安装版对照：7 节点探针状态一致 active、dbg 拉取正常、无模拟值；截图存档；若 Web 端仍异常 → 深查部署 chunk 与缓存（清 service worker/强刷）。

**P3 退出标准**：双端节点状态一致 + 截图 + 状态回填本档。

## P4-P7 概要（执行时另立落档细化）

- **P4**：`useOpsPanelMetrics` 扩展 `/api/metrics` 的 vllm.rates（吞吐/tokens）与 dcgm 每卡明细 → 节点详情弹窗真实呈现；端点/频率仍走 ssot 可编辑。
- **P5**：x64 镜像重试与 blockmap（temp 文件名空格链路）；`@electron/notarize` 公证流水线（需 Developer ID 证书——**负责人提供**）。
- **P6**：等输入项各自成批；M4 设计文档承诺 2026-11-24 前落档（node-slice 多 WS 连接方案 + hub 汇聚对比三方案）。
- **P7**：文档体系统一收口（README 索引、CI 挂 docs:check、双域名裁决落地）。

## 风险与纪律

| 风险 | 对策 |
| ---- | ---- |
| 删除类改动破坏隐藏引用 | 每删必先全仓 grep 引用面（本计划已预核）+ 三门禁兜底 |
| supabase 解耦改变登录语义 | 保持 ghost 一键进入语义不变；浏览器实证登录-登出-再进 |
| 阶段间状态漂移 | 本档状态列为唯一进度 SSOT；完成即回填 + 注册表登记 |
| 假数据回潮 | 红线不变：新增数据一律 slice persist + 可编辑，禁止硬编码 |
