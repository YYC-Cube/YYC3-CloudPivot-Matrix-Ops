## 二、F-05 加固明细（c20faaf）

消费者影响评估先行：渲染层仅 `notification` 通道在用（usePushNotifications），文件/DB/Shell 通道无生产调用方 → 加固零破坏。

| 通道 | 加固 |
| ---- | ---- |
| FILE_DELETE/EXISTS/LIST/STAT/MKDIR/COPY/MOVE（7 通道） | 补 `pathGuard`（绝对路径 + NUL 拒绝）与 `permissionManager` 路径权限检查，与 FILE_READ/WRITE 既有策略一致化 |
| SHELL_OPEN | 双模白名单：http(s) → openExternal；绝对路径 → openPath；拒绝 file:// 等协议与 NUL 注入 |
| APP_PATH | 十类路径名白名单枚举（home/appData/userData/tmp/documents/downloads/desktop/logs/crashDumps/tmp），防任意特殊路径探测 |
| DIALOG×3 | options 普通对象守卫 |
| DB_EXECUTE/DB_QUERY | SQL 非空 string + params 必须数组（**参数绑定约束固化**，接入真实驱动后禁止拼接 SQL） |

验证：`tsc -p electron/tsconfig.json --noEmit` 0 错误。
