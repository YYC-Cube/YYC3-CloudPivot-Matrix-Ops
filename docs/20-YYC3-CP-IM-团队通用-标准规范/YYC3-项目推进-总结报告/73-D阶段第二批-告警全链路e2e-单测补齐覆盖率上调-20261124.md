## 二、告警全链路 e2e（agent-linked 第 3 例，7.6s）

`告警规则创建 → 下发 → agent 回读 → 面板删除 → agent 确认不含`：

1. 面板点「创建规则」→ 填名（e2e-closure-rule）→ 选真实 WS 节点 chip（**异步到达，先等 `[data-testid^="node-"]` 渲染再点**——首版写死 yyc3-22 因节点未到达超时，实测修正）→ 提交；
2. 防抖下发 → chip「已同步 1 条（含回读）」；
3. **Node 侧 GET agent /rules 权威回读**：规则存在（闭环外部证据）；
4. 面板删除该规则（`rule-card-<id>` 卡片 + `delete-rule-btn`）→ 轮询 agent 确认已不含。

配套源改动（a11y + 可测性）：RuleCard 根部 `data-testid="rule-card-<id>"`、删除按钮 `aria-label="删除规则"` + `delete-rule-btn`；GlassCard 本就透传 rest props（无需改）。

开发中实测两坑：① 节点 chips 异步渲染需显式等待；② agent 侧规则 id 可能被 sanitize 重写——**删除定位改按「文本过滤卡片」，不依赖两侧 id 相等**。
