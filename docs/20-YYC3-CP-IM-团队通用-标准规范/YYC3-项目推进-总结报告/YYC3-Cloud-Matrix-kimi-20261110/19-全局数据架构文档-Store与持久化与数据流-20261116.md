# 落档 19 · 全局数据架构文档

> 2026-11-16 源码实证。数据架构三原则：**无后端、本地持久、真实优先（demoMode 闸门）**。

## 一、三层数据架构

```
┌─ 实时层（易失）────────────────────────────────────
│  yyc3-agent WS 推送 → node-slice / metrics-slice 聚合
│  连接状态机：真连态 = agent 数据；未连态 = 数据总控用户自维护条目
├─ 持久层（localStorage，31 键）─────────────────────
│  Zustand persist，version + migrate 管理schema演进
│  假种子一律 migrate 按 ID 精确清除，保留用户真实数据
├─ 外部层（用户自配）────────────────────────────────
│  OpenAI 兼容模型端点（provider-slice 统一保管 baseUrl/apiKey）
│  Electron IPC（桌面壳）、Ollama 同源代理
└──────────────────────────────────────────────────
```

## 四、核心数据流（三条主链路）

### 1. 监控链路（真实指标）

```
yyc3-agent（3113）─WS→ websocket-manager → node-slice.applySnapshot
  → metrics-slice 聚合（liveModelDist 等派生）
  → Dashboard / 数据监控 / 巡查
未连态：DataEditorPanel（数据总控）用户自维护条目 → metrics-slice → 图表如实展示
```

### 2. AI Family 对话链路（落档 15）

```
用户输入（FamilyChat/CommCenter/VoiceSystem）
  → FamilyAIService.chat / chatGroup
  → checkMemberReadiness：member slice binding → configuredModels 精确匹配 → 密钥校验
  → 就绪：callRealLLM（system=三件套人格可编辑，30s 超时，history 10 条）
  → 未就绪/失败：source:"error" → UI 诚实离线胶囊（demoMode 开才走演示引擎+「演示」徽标）
  → addMessage → family-chat-slice / commMessages persist
```

### 3. 配置链路（系统管理 = 全局数据源总控）

```
SystemSettings / VariableCenter / ConfigCenter / ModelProviderPanel
  → settings-ssot-slice（toggles/values/variables）/ provider-slice（模型端点）
  → 全局消费：demoMode 闸门、WS 地址、API 地址、模型接线
  → export-center / ConfigExportCenter 导出（family-settings 支持 v2.0 envelope 导入导出）
```

## 六、demoMode 闸门（演示数据唯一合法通道）

- 开关：`useSettingsSSOT((s) => s.toggles.demoMode)`，默认 **false**（`settings-ssot-slice.ts:147`）。
- 规则：demoMode 关 = 真实路径，不可达 → 诚实离线/空态，**绝不回退假数据**；demoMode 开 = 演示引擎输出，UI 必须挂「演示」标识。
- 已接入：family-ai-service（对话演示引擎）。待排查：其余模块是否仍有绕过闸门的硬编码演示数据（落档 17 各 ⚠ 项）。
