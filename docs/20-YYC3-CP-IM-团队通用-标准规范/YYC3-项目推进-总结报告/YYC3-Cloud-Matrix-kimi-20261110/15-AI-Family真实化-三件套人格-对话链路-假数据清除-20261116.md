# 落档 15 · AI Family 真实化

## 一、本轮目标（用户三项决策）

1. **曌·中枢所有完整代码复用进行适用性设计，不修改原有代码** —— 原仓只读，人格内容作数据导入。
2. **本地自主编辑选择设计** —— 模型 / 服务商 / 人格均可编辑，呈现便捷化使用。
3. **Cloud-Matrix 本地项目数据不出本地** —— localStorage 持久化 + OpenAI 兼容网关自配。

NAS gateway 兼容性 / 密钥、模型选择（N2:8100 vs super-vl）留给用户在「模型管理」界面自行配置，**零硬编码**；Flask 运行时按中枢官方口径「退役中」放弃，消费形态 = OpenAI 兼容网关 + 人格三件套。

## 二、架构设计（真实优先 · 诚实离线）

```
成员 modelAssignment（可编辑，member slice = SSOT）
  → provider-slice configuredModels 精确匹配（providerId + model）
  → OpenAI 兼容 /chat/completions 真实调用
    · system = 成员 systemPrompt（可编辑）→ 缺省回退曌·中枢三件套
    · 30s 超时，history 10 条
  → 未绑定 / 未配置 / 缺 Key / 不可达 → source:"error" 诚实离线，绝不回退假数据
demoMode 开启（系统管理开关）→ 演示引擎（agent/mock），UI 挂「演示」徽标
```

群聊：优先 `getActiveModel()`，否则寻找第一个就绪成员绑定；`【短名】`前缀解析回复成员。

## 六、使用指引（模型接线三步）

1. 「模型管理」添加服务商（内置智谱/DeepSeek/Ollama，或自定义 NAS gateway）与模型实例（填 baseUrl/apiKey）。
2. 「AI Family → 模型设置」为每位家人选择已配置的模型（绑定双写 member slice，对话链路实时生效）。
3. 回到「家人对话」即可真实对话；未接线的家人会诚实标注离线原因。
