## 二、外部数据通道（真实 API 面）

### 1. yyc3-agent 本地服务（核心数据面）

| 通道 | 默认地址 | 配置入口 | 消费者 |
| --- | --- | --- | --- |
| HTTP API | `http://localhost:3113/api` | `env-config.ts:88` `API_BASE_URL`，可在「环境配置」页改 | 操作中心、文件管理、数据库、备份、巡检 |
| WebSocket | `ws://localhost:3113/ws` | `api-config.ts:43` `DEFAULT_WS_ENDPOINT`，可在配置中心改 | Dashboard 节点聚合、实时指标推送 |
| 采集面 | cpu / memory / disk | — | ⚠ gpu/network/error_rate/throughput 待扩展（落档 17 #11） |

WS 令牌配置见落档 04《演示模式与WS令牌配置-运维手册》。

### 2. 模型服务端点（用户自配，零硬编码）

| 通道 | 说明 | 证据 |
| --- | --- | --- |
| OpenAI 兼容端点 | provider-slice `configuredModels` 管理 baseUrl/apiKey/proxyUrl；URL 语义 `{base}/chat/completions`，有 proxyUrl 则 `{proxy}/{endpoint}` | `src/app/lib/family-ai-service.ts:120-131` |
| Ollama | 默认 `http://localhost:11434`，走同源代理 `/api/v1/llm/ollama` | `env-config.ts:90-91`、`ollama-url.ts` |
| 自定义服务商 | NAS gateway 等 OpenAI 兼容服务由此接入（如 `http://100.65.172.88:8000/v1`） | provider-slice 自定义 provider 支持 |
| 消费方 | AI Family 对话（family-ai-service）、SDK 对话（useBigModelSDK）、模型设置诊断（connection-test-engine） | 落档 15 |

### 3. Electron 桌面桥（桌面壳形态）

| 通道 | 说明 | 证据 |
| --- | --- | --- |
| `window.yyc3` IPC | 文件对话框、系统信息（CPU/内存/磁盘/网络/进程）、数据库执行 | `src/app/lib/bridge-client.ts`、`src/shared/ipc-types.ts` |
| 环境检测 | `isElectron()`：浏览器态返回 null 并降级 | `bridge-client.ts:31-38` |

## 三、路由级数据流总图

```
浏览器 SPA（HashRouter，43+18 路由）
  ├─ 实时监控类页面 ←WS→ yyc3-agent（3113）→ 真实节点指标
  ├─ 运维操作类页面 ←HTTP→ yyc3-agent（3113）→ 真实文件/进程/数据库
  ├─ AI 对话类页面 ←HTTPS→ 用户自配 OpenAI 兼容端点（智谱/DeepSeek/Ollama/NAS gateway）
  ├─ 桌面壳形态 ←IPC→ window.yyc3（Electron preload）
  └─ 全部业务状态 ←persist→ localStorage（31 个键，见落档 19）
```
