## 二、本地封装部署手册（标准流程）

### 2.1 构建（项目根目录）

```bash
pnpm build:mac          # tsc + vite build --base=./ + electron-builder（mac 双架构 dmg）
# 网络受限时：
CSC_IDENTITY_AUTO_DISCOVERY=false ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/" pnpm build:mac
# 产物：dist-electron/YYC3-PivotMatrixOps-{version}-mac-{arm64|x64}.dmg(+.blockmap)
```

### 2.2 安装/更新（主控机）

```bash
# dmg 安装或直接热更 .app：
rm -rf "/Applications/YYC3 PivotMatrix Ops.app"
cp -R "dist-electron/mac-arm64/YYC3 PivotMatrix Ops.app" /Applications/
xattr -dr com.apple.quarantine "/Applications/YYC3 PivotMatrix Ops.app"   # 免签发首启
killall Dock    # 图标缓存刷新（重装同 bundle id 后 Dock 旧图标）
```

### 2.3 Web 面板部署

```bash
./node_modules/.bin/vite build --base=./    # 桌面/部署共用相对 base（严禁 build:pages 后直接打包→白屏）
# server.mjs 读磁盘 dist，构建即部署；LaunchAgent 自动守护（3118）
```

### 2.4 首配（新环境三步）

1. WS 令牌：面板「系统设置 → WebSocket → 粘贴 agent 令牌」（`~/.yyc3-cloud-matrix/agent-token`）→ 保存即连
2. OpsPanel 源：同分区「OpsPanel 数据源地址」（默认 127.0.0.1:7864，可改可关）
3. 全节点清单：「数据看盘 → 添加节点」表单录入（或导入 persist）；本机节点由 agent 自动上屏

### 2.5 封装红线（P1-P5 实证沉淀）

- electron 打包必须 `--base=./`（与 Pages 链隔离）；`build.files` 显式枚举产物目录（防递归吞历史 dmg / 漏 src 产物）
- artifactName **不含空格**（blockmap 链路）；plist 的 xmldom 钉 0.8（workspace 已作用域覆写）
- PROD CSP 放行 `ws/http://localhost:*|127.0.0.1:*`；Electron 与 Web 的 localStorage 分源（两端各自首配）
