## 一、目标与边界

落实落档 57 第 3 条原则「源控在系统管理」：新增 **系统管理 → 数据源**（`/sources`），把 agent / OpsPanel / Ollama / NAS / DGX / 3118 反代 / DB / FS 统一登记，支持**增、删、改、测**。

- **本地自用红线**：地址校验只允许本机 / 局域网 / Tailscale（`localhost`、`127.*`、`10.*`、`192.168.*`、`172.16-31.*`、`100.64-127.*`、`*.local`）；公网地址直接拒绝。
- **不做第二套事实源**：agent 与 OpsPanel 是「绑定源」，页面编辑写回 Settings SSOT（`wsEndpoint` / `opsPanelBaseUrl`），注册表只做镜像展示；其余源由注册表持久化。
- **必需源不可删**：绑定源删除按钮禁用（运行必需）；其余内置源（NAS/DGX 等）与自定义源均可删。

## 二、实现

| 层 | 文件 | 内容 |
| ---- | ---- | ---- |
| Store | `src/app/store/slices/source-registry-slice.ts` | 持久化键 `yyc3-source-registry`；8 个默认源；`addSource/updateSource/removeSource/recordTest`；`resolveSourceUrl` / `setSourceUrl` 处理绑定源 |
| 页面 | `src/app/modules/admin/SourceRegistryPage.tsx` | 列表 + 类型徽标 + 「系统设置同步」标记 + 启停/测试/编辑/删除 + 新增表单 + 统计卡 |
| 导航 | `Sidebar.tsx` / `routes.tsx` / i18n | 系统管理 → 数据源（`nav.sources`，中英双语） |
| 测试 | `src/app/__tests__/store/source-registry-slice.test.ts` | 默认源、增删、绑定源不可删、测试写入、绑定写回 SSOT（5 例） |

**测试通道**：agent 走 WebSocket 连通（带 SSOT 令牌）；OpsPanel `/api/nodes`；Ollama `/api/tags`；NAS/DGX `/v1/models`；3118 `/`；FS `/files`；DB 明确标记「未接：仓库内无 /api/db 后端」。

## 四、与现有链路的关系

- **已生效**：设置页与数据源页编辑 agent/OpsPanel 地址写同一 SSOT，`useWebSocketData` / OpsPanel 三个 Hook 立即使用新地址。
- **登记未接线**：NAS / DGX / 3118 反代 / DB / FS 目前仅登记与测试，模型调用仍按 provider 配置走 3118；后续将这些源的地址接入受控配置（不再是 deploy env 硬编码）。
- **没有新增转接**：3118 反代保留为本地反代数据源（落档 57 定案）。

3. 告警闭环回读（`GET /rules` → 「已生效」标识）。
4. 数据库三套 store 合并 + `/api/db` 决策。
