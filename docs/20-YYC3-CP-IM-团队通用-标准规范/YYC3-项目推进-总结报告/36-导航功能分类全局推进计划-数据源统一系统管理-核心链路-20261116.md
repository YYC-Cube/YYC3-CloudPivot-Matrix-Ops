## 一、统一数据源「系统管理」与核心链路（全局功能逻辑）

**原则（唯一事实源声明）**：**系统管理域 = 全项目数据源总控（SSOT）**——一切可编辑变量、端点、开关、清单均在此定义并即时生效，各功能域只做消费方，禁止域内私建数据源。

```
┌──────────────── 系统管理（数据源统一总控）────────────────┐
│ 系统设置(settings-ssot：WS端点/令牌/OpsPanel源/demoMode…) │
│ 变量中心 · 配置中心 · 环境配置 · 统一设置                   │
│ 模型管理(provider-slice：OpenAI兼容端点/密钥/激活模型)     │
│ 数据总控(data-editor：未连态数据维护) · 存储管理 · 导出中心 │
└──────┬───────────────┬───────────────┬────────────────┘
       │ 消费           │ 消费           │ 消费
  监控/运维域      AI/AI Family 域    业务/开发域
       ▲               ▲
       │ 三条外部数据通道（端点全部由系统管理配置）
  ① yyc3-agent(3113)：WS 快照/HTTP 动作·文件·巡检【主控机常驻】
  ② OpsPanel(7864)：7 节点探针/每卡 DCGM/vLLM【CORS 已通】
  ③ 模型端点(用户自配)：智谱/DeepSeek/Ollama/NAS gateway
  ④ Electron 桥(桌面壳 IPC) —— Web/Pages/安装版三形态同一 dist
```

**API 路由核心链路**：前端 43→42 条 Hash 路由 + 18 条 AI Family 子路由的权威总表=**落档 18**（逐条组件/数据源标注，本次仅 −1：`/ide` 拆除）；外部通道明细=落档 18 §二 + 落档 34 §2.4；数据架构三链路（监控/AI 对话/配置）=落档 19 §四。supabase 已全局退役（落档 33）。
