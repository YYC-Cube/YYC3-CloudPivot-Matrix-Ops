## 一、三处断点的发现与修复（4f31e8d）

| # | 断点 | 根因 | 修复 | 验证 |
| ---- | ---- | ---- | ---- | ---- |
| 1 | Electron 二进制不落盘 | 本机 pnpm **10.17.0** 仅识别 `onlyBuiltDependencies`（workspace 里的 `allowBuilds` 是 pnpm 11 字段），postinstall 被静默跳过 | 补 `onlyBuiltDependencies: [electron, esbuild, electron-winstaller]` | `pnpm rebuild electron` → postinstall Done → Electron.app 就位 |
| 2 | 窗口白屏（资源加载失败） | `main.ts:82` 加载 `'../dist'`，但 `__dirname` 在 `dist-electron/electron/`（tsc rootDir 上浮布局）→ 实指 `dist-electron/dist`（不存在） | 改 `'../../dist'`（打包后 app 根相对关系不变） | 冒烟日志 0 × ERR_FILE_NOT_FOUND |
| 3 | 打包 schema 拒绝 | electron-builder 26.15.3 已废弃 `build.win.signingHashAlgorithms` | 从 package.json 删除该字段 | schema 校验通过，打包继续 |

## 二、验证链（冒烟 → 封装 → 产物）

```
electron . 冒烟        主进程 IPC 全注册 + 12s 存活 + 0 资源错误       ✅
  ↓
pnpm build:mac         tsc + vite build + electron-builder             ✅（修复 3 处后）
  ↓
arm64 dmg 707M         包体启动冒烟：IPC 注册 + 10s 存活 + 0 资源错误   ✅
  ↓
x64 dmg 2.1G           挂载验证：Applications + .app + 可执行文件齐全    ✅
```

产物位置：`dist-electron/YYC3 PivotMatrix Ops-3.4.1-mac-{arm64|x64}.dmg`

**已知问题登记**：
1. x64 dmg 收尾 blockmap 计算 ENOENT（temp 文件名带空格链路问题），dmg 本体完整可挂载；缺失 blockmap 仅影响 electron-updater 自动增量更新——**双架构补 blockmap 排入批 5**
2. 产物体积 707M/2.1G 偏大：`extraResources` 全量拷贝 `public/`（含未裁决资产 `项目导航-对齐截图/`）——**再次强化该资产裁决的紧迫性**（入册归档则应移出 public/；否则建议移出并加入 .gitignore）
3. 未签名/未公证：分发需 Apple Developer ID + notarize 流程（SECURITY 配置就绪，@electron/notarize 已在依赖），排批 5

## 三、批 5 入口

1. blockmap 双架构修复（空格文件名链路）→ electron-updater 自动更新链路打通
2. 签名+公证流水线（Apple Developer ID，对外分发前置）
3. 产物瘦身（extraResources 白名单化，剥离未裁决资产；预期 dmg 可减半以上）
4. #12 实测（等 API key）、#10/#13（等用户输入）、M4 方案设计（承诺 2026-11-24 前落档）
