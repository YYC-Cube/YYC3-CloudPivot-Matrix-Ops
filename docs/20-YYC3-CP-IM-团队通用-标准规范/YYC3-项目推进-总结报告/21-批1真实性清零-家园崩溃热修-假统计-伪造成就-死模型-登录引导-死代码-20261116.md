## 二、P0 根因与修法（重点）

### 根因

`family-member-slice.ts` 中成员 `icon` 字段是 lucide-react 的 forwardRef **组件对象**。zustand persist 将其序列化为 `{}` 写入 localStorage；rehydrate 后 `icon` 变成普通对象，React 渲染 `<Icon>` 时报「Element type is invalid: got object」。用户此前在页面上编辑人格并保存，触发了持久化写入，导致污染数据进入 localStorage，页面一加载即崩。

### 修法（四重防护）

1. persist `version: 1 → 2`
2. `partialize` 序列化时剔除 `icon`（函数/组件对象本就不该入持久层）
3. `migrate` 任意旧版本剥离历史误存的 icon 字段（保留原 v0→v1 systemPrompt 回填逻辑）
4. 新增 `merge`：rehydrate 时按成员 id 从 `DEFAULT_MEMBERS` 恢复 icon 组件引用，未知 id 兜底取第一位成员的 icon

### 实证

浏览器 localStorage `yyc3-family-members` 残留 version 1 污染数据，加载页面后自动 migrate 至 version 2，icon 字段被剥离，页面恢复渲染，无崩溃文本。
