## 一、接线全链路（ZCode 式四设置项）

| 步 | 操作 | 结果 |
| ---- | ---- | ---- |
| 0 本地模型 | `ollama serve`（0.24.0）· 已装 **family-coder-14b-q4**（qwen3-14.8B Q4_K_M · 9GB）· `/v1` 直探推理 ✓ | 🟢 服务就绪 |
| 1 自定义服务商 | `#/models → 自定义服务商`：名称「本地 Ollama 14B」/ **API URL `http://127.0.0.1:11434/v1`**（可任意填写）/ 鉴权 bearer / 模型名 `family-coder-14b-q4:latest` | 🟢 注册表 +1（4 服务商） |
| 2 已配置模型 | AddModelModal 流程（服务商→模型→密钥任意值）→ **persist 直注 ConfiguredModel**（见 §三-1） | 🟢 总模型数 1 |
| 3 真实连接测试 | 卡片「测试连接」→ connection-test-engine 三步：**端点 3ms ✓ 模型已装 2ms ✓ 推理 2106ms ✓**（总 2116ms）→ 自动激活 | 🟢 活跃模型 1 |
| 4 真实对话往返 | `#/ai-family/chat` 群聊发送「天枢，用一句话介绍你自己」→ **本地 14B 真实生成**：「天枢是YYC³(YanYuCloudCube)开发的AI浮窗门户，是家族AI应用的统一入口和智能调度中心。」 | 🟢 往返闭环 |

## 二、合规对照

- **数据源统一**：模型端点经「系统管理→模型管理」（provider-slice）单一管控，各域消费 ✓（落档 36 口径）
- **零硬编码**：URL/密钥/模型名全部 UI 可编辑持久化；密钥任意值符合本地 bearer 免校验实态
- 落档 15「AI 对话链路架构就绪」→ 本档补上**本地端点的实证闭环**（诚实离线 → 真实在线）

## 三、过程发现（登记后续）

| # | 发现 | 状态 |
| ---- | ---- | ---- |
| 1 | AddModelModal「添加模型」提交键在四项齐备时仍禁用（Playwright fill 密钥后未解锁；疑 requiresApiKey 状态联动缺陷）——本档经 persist 直注等效绕过 | 🟡 P6 后续小修（定位 React 状态链） |
| 2 | `#/ai-family/models`（家人模型设置页）渲染挂起：两个页签 evaluate 均 32s 超时、其一 renderer "target closed"——疑 8 成员卡并发诊断或自定义 provider 图标缺省引发 | 🟡 P6 后续排查（复现路径已记录） |
