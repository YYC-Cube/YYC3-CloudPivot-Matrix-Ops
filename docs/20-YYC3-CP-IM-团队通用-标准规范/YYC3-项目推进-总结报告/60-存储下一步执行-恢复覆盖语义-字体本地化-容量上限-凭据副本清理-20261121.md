## 二、恢复语义（覆盖）

`importFullBackup(json, { replace = true })`：

1. **版本校验**：`_tool` + `_version ≤ 2`；
2. **覆盖**：`clearAllStorage()` 清项目 localStorage 键 + 全部 IndexedDB store；
3. **会话保留**：清理前快照 `yyc3_session` / `yyc3_ghost`，清理后恢复（恢复数据不强制登出）；
4. **白名单导入**：只恢复项目键，跳过认证键、非项目键、`[REDACTED]` 占位；
5. **UI**：全量恢复前 `confirm` 明确「覆盖当前全部本地数据（认证会话保留）」，成功后 700ms 重载，让所有 zustand 内存态从新持久化重新水合；
6. **文案纠偏**：删除「加密引擎可用」的失实提示，改为「备份已脱敏：密钥 / 密码导出为 [REDACTED]」。

## 三、独立性：字体本地化

- 移除 `@import url('https://fonts.googleapis.com/...')`。
- 下载 Orbitron（可变字体，单文件覆盖 400–900）与 Rajdhani 300–700（5 个静态字重）到 `src/styles/fonts/`，由 Vite 打包。
- 生成 `src/styles/fonts.css`（`@font-face` + `font-display: swap`，相对路径）。
- 实测：`dist/assets` 含 6 个 woff2；`dist` 内 **零** `fonts.googleapis.com` / `fonts.gstatic.com` 引用；字体资源 HTTP 200。

> 字体许可：SIL Open Font License 1.1（Google Fonts），已随文件本地化。

## 四、容量与凭据副本

| 项 | 改动 |
| ---- | ---- |
| `fs-slice` | 新增 `partialize`：内容缓存最多 20 个文件 / 256KB（UTF-16 估算），超出不持久化；persist `version: 1` |
| `family-settings` | `partialize` 排除 `providerKeys`（历史死副本；真实 Key 在 `provider-slice`），不再落盘 |
| `variable-center` | 删除 5 个 `secret.*` 定义（OpenAI/Zhipu/DeepSeek/Kimi/Anthropic）——无消费者且明文存储；凭据只允许在模型管理或加密仓库 |

## 五、单源修复

- `settings-ssot` 的 `onAPIConfigChange` / `onEnvConfigChange` 此前直接改闭包对象（不触发订阅与持久化）。改为 `useSettingsSSOT.setState(...)`，高级设置/环境变量修改现在真正写回 SSOT。

## 七、仍未完成（下一步）

1. **凭据加密迁移**：provider `apiKey`、SSOT `aiApiKey/wsToken/dbPassword` 仍为 localStorage 明文；需接入 `crypto-vault`（异步水合）或 OS keychain，并迁移现有明文。
2. **数据库三套 store 合并**：`/database`（IndexedDB）、`/db-connections`（localStorage）、`/connection-monitor`（内存 manager）。
3. **Family 双绑定**：`family-settings.modelAssignments` 与 `family-member` 两套默认值不一致，运行时只读 member slice。
4. **其余隐性外联**：`via.placeholder.com`、`soundhelix.com` 音频、Google STUN、WebLLM 权重下载、百度/Google 连通性探测。
5. **部署路径**：`deploy/*.plist` 与 `nginx.conf` 仍指向旧仓库。
6. **IDB 历史表上限/TTL**：patrol/loop/operationLogs/reports/queryHistory/fileVersions 等。
