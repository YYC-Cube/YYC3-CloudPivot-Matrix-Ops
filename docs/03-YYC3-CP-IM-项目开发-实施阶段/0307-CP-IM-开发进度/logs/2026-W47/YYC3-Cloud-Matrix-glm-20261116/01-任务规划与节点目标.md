## 一、目标概述

完成零前置认知的首次全维度技术调研并落档，同时按团队标规建立可持续运转的项目文档日志体系；产出 P0~P3 分级问题清单作为后续会话的任务源。

## 二、任务拆解

| 编号 | 任务 | 优先级 | 依赖 | 计划状态 | 验收标准 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| T-01 | 全仓信息采集（业务/技术/代码/协作四层 + 标规研读） | P0 | 无 | ✅ | 四层信息表齐全，缺失项标注待确认及确认路径 |
| T-02 | 质量门禁实测（test:ci / type-check / lint / build:pages） | P0 | T-01 | ✅ | 四项命令实测输出落档，失败项定位根因到文件:行 |
| T-03 | 六维深度分析（架构/质量/债务/性能/安全/可维护性） | P0 | T-01 | ✅ | 每维含「现状+问题+影响」三层结论 |
| T-04 | 建立文档日志体系（006-总纲 + 四件套模板 + 注册表 + 校验脚本） | P0 | T-01 | 🔵 | `pnpm docs:check` 对新体系文档零 error；四件套齐备 |
| T-05 | 落档会话四件套（00 审核 / 01 规划 / 02 日志 / 03 总结） | P0 | T-02,T-03 | 🔵 | 收尾检查清单全勾，含下次会话启动指南 |
| T-06 | 输出调研总结（P0~P3 清单 + 短中长期建议 + 协作指引） | P1 | T-03 | 🔵 | 用户侧可见完整报告 |
| T-07 | 修复 16 个失败测试（同步真实化断言） | P1 | 无（可下会话） | ⬜ | `pnpm test:ci` 5063 全绿 |
| T-08 | 修复 Electron 打包链路（main 路径对齐） | P1 | 无（可下会话） | ⬜ | `electron .` 实测启动成功 |

状态枚举：⬜ 未开始 / 🔵 进行中 / ✅ 完成 / ⏸ 暂停 / ❌ 取消

## 三、节点目标与里程碑

| 节点 | 目标产出 | 目标时间 | 验收方式 |
| ---- | ---- | ---- | ---- |
| M1 | 三探查代理报告 + 门禁实测四结果 | 本次会话前半 | 代理报告归档 + 命令输出 |
| M2 | 日志体系五件（总纲/模板×4/注册表/脚本/索引更新） | 本次会话中段 | `pnpm docs:check` 0 error |
| M3 | 四件套落档 + 会话总结 | 本次会话收尾 | 03-总结含启动指南与 TOP3 |

## 四、风险与预案

| 风险 | 影响 | 预案 |
| ---- | ---- | ---- |
| 工作区中间态（66删/31新/14改）造成基线误判 | 调研结论失真 | 所有结论标注「HEAD vs 工作区」口径，失败测试根因已双端比对 |
| 新体系与既有 20-目录落档惯例冲突 | 双轨混乱 | 006-总纲明确定位三轨关系：会话轨新增、落档轨沿用、版本轨沿用 |
| docs:check 扫全库误伤旧格式文档 | 门禁噪音 | 扫描范围默认限定日志体系目录，支持参数扩展 |
